Dash

A free tool that turns a player's own VALORANT match data into round-by-round stats, playstyle groups and weapon predictions, so beginners can see what to work on after a match.

What it is

Dash is a statistical analysis tool for players who want to understand their own play. A player signs in, opts in to sharing their own match data, and loads a match. The dashboard then shows what happened in every round: kills, deaths, assists, damage, headshot rate, the weapon bought, the credits at the start of the round and whether the round was won, split by attack and defense.

Each stat is compared with the match average and explained in plain words, for example: "Aim is okay but the player rarely helps teammates get kills." Dash reports only on finished matches. It does not rank players, does not scout opponents and gives nothing during a match.

Who it is for

Beginners

Players who do not know which of their numbers (aim, damage, team play, economy) is holding them back.

Improving players

Players who want to track the same stats across several matches and see if a change in habits helped.

Students of the game

People learning how the in-game economy and weapon choice go together.

How it works

1. Sign inThe player opts in to share their own matches
2. Match dataOfficial VALORANT match data for that player's matches
3. AnonymizeOther players become p1, p2 ... and names and IDs are dropped
4. AnalyseRules and two machine learning methods run in the browser
5. ShowCharts and plain-language feedback

The machine learning

Playstyle groups (k-means)
Players in a match are grouped by headshot rate, damage per round, assists per round, K/D and survival. Each group is named from its averages, such as "support-leaning all-rounder".
Weapon prediction (k-nearest neighbours)
The model learns from the player's own earlier rounds how credits, side and round number relate to the weapon bought, then predicts the likely weapon. Its accuracy is shown next to a simple baseline so the player can see whether it beats guessing.
Good / not good rating
A nearest-neighbours check on headshot rate and damage that the player can teach with their own examples, shown next to a fixed-rule rating.

Riot API use

APIs used
VAL-MATCH-V1 only: the match list for the signed-in player and the match details (round results, player stats per round, economy).
When data is requested
Only when the player asks to load their matches, one match at a time. A match already downloaded is not downloaded again.
Rate limits
Requests stay under the key's limits, and Dash waits as long as the API asks after a 429 response.
Not used
No live game data, no game client hooks, no memory reading and no other Riot API.

Current status and limits

Dash is a working prototype made for a school project about using AI for good. The dashboard and the match converter have been tested with example data. They have not yet been tested with live Riot API responses, which is the reason for the production key application. Riot Sign On is not built yet.

  • Riot's match data gives how many shots hit the head, not which kills were headshots, so headshot % is an estimate and is labelled that way.
  • Shots fired are not provided, so accuracy is not shown for VALORANT.
  • The rating cut-offs (for example what counts as a good headshot rate) are starting values that the player can change.
